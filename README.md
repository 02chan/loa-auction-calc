# 로스트아크 레이드 경매 계산기 (LoaAuctionCalc)

레이드 **전리품 경매** 화면을 읽어서 **추천 입찰가**와 **손익분기가**를 계산해 주는 Windows용 작은 창 프로그램입니다.

- 경매 화면의 **거래소 최저가**와 **아이템명**을 Windows 내장 OCR(한국어)로 읽습니다.
- **4인 / 8인** 버튼으로 인원을 고르면 바로 계산합니다.
- 결과는 항상 위에 떠 있는 작은 창에 표시되고, 인식 기록은 `history.csv`에 남습니다.
- 프로그램은 숫자를 **보여 주기만** 합니다. 입찰은 사람이 직접 합니다.

## 실행 방법

### exe로 실행
1. `LoaAuctionCalc.exe`를 원하는 폴더에 둡니다. `config.json`, `history.csv`가 같은 폴더에 생깁니다.
2. 더블클릭해서 실행하면 작은 창이 뜹니다(항상 위).

### 소스로 실행 (개발용)
```powershell
py -3.11 -m venv .venv            # Python 3.11 이상
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m loa_auction
```

## 사용법

| 방법 | 동작 |
| --- | --- |
| **F8** (기본 단축키) | 누른 순간 화면(모든 모니터)을 **한 번** 캡처 → 인식 → 계산 |
| **[캡처] 버튼** | F8과 같습니다. 게임 창이 앞에 있을 때 게임이 F8 입력을 막아 반응이 없으면, 계산기 창의 **[캡처]**를 마우스로 누르세요 |
| **Ctrl+V** (미니 창 선택 상태) | 클립보드 이미지를 인식 → 계산. `Win+Shift+S`로 경매 창을 잘라 복사한 뒤 붙여넣으면 됩니다 |
| **4인 / 8인** 버튼 | 인원 선택. 바꾸면 즉시 재계산되고 다음 실행 때도 유지됩니다 |
| **가격 칸** | 인식된 가격이 자동으로 들어갑니다. 직접 고치면 즉시 재계산됩니다 |
| **추천 입찰가 자동 복사** | 인식에 성공하거나, 4인/8인을 바꾸거나, 가격을 직접 고친 뒤 Enter(또는 칸 벗어나기)를 하면 추천 입찰가가 **쉼표 없이**(예: `11335`) 클립보드에 들어갑니다. 게임 입찰 칸에 직접 Ctrl+V 하세요 |
| **숫자 클릭** | `판매 손익분기`·`사용 손익분기`(또는 추천 입찰가) 숫자를 클릭하면 그 값이 쉼표 없이 복사됩니다 |
| **▸ 최근 기록** | 최근 10건을 펼쳐 보고, `실제낙찰가` 칸을 더블클릭해 실제로 낙찰된 금액을 적을 수 있습니다 |
| **창 옮기기** | 윈도우 제목 표시줄이 없는 창입니다. 맨 윗줄(아이콘·아이템명)을 끌어서 옮깁니다 |
| **[—] 접기** | 창을 작은 프로그램 아이콘으로 접습니다. 아이콘은 항상 위에 떠 있고, **클릭하면 원래 창으로 펼쳐지며**, 끌어서 옮길 수 있습니다. 오른쪽 클릭하면 `펼치기 / 종료` 메뉴가 나옵니다. 아이콘을 끌어다 놓은 자리는 기억해서, 펼쳤다가 다시 접어도(프로그램을 다시 켜도) 그 자리로 돌아갑니다 |
| **[✕] 종료** | 설정을 저장하고 단축키를 해제한 뒤 프로그램을 끝냅니다 |

- 아이콘으로 접혀 있어도 **F8은 그대로 동작**하고, 인식 결과가 나오면 창이 자동으로 펼쳐집니다(추천 입찰가 자동 복사도 그대로).

- 인식에 실패하면 아이템명 자리에 **인식 실패**가 표시되고 가격 칸이 비워집니다. 경매 창의 `거래소 최저가` 줄이 가려지지 않게 다시 시도하세요.
- 클립보드에 이미지가 없으면 창 아래 상태줄에 안내가 나옵니다. 이 창이 방금 복사한 숫자가 클립보드에 있을 때 Ctrl+V를 눌러도 가격 칸에 붙지 않고 같은 안내가 나옵니다(새 캡처를 잊은 경우).
- 숫자를 복사하면 상태줄에 `판매 손익분기 12468 복사됨`처럼 표시됩니다.
- 게임 화면이 앞에 있을 때 F8을 눌러도 반응이 없다면, 게임이 등록 단축키를 받지 않는 경우입니다. 이 프로그램은 운영정책상 키보드 후킹을 쓰지 않으므로 이때는 **[캡처] 버튼**을 쓰세요(계산기를 게임 옆 모니터에 두면 편합니다).
- 모니터가 여러 대면 모두 캡처해 주 모니터부터 차례로 경매 창을 찾습니다.
- 단축키는 `config.json`의 `hotkey` 값으로 바꿀 수 있습니다. 예) `"F9"`, `"Ctrl+Shift+A"`. 다른 프로그램이 이미 쓰고 있으면 상태줄에 **등록 실패**가 표시되며, 이때도 Ctrl+V는 그대로 쓸 수 있습니다.

### 창 모드 권장
게임을 **창 모드** 또는 **전체 창 모드(테두리 없는 창)** 로 두는 것을 권장합니다. 전체 화면(독점) 모드에서는 캡처 이미지가 검게 나오거나 미니 창이 게임 위에 보이지 않을 수 있습니다. 미니 창은 경매 창의 `거래소 최저가` 줄을 가리지 않는 곳에 두세요.

## 계산식

P = 거래소 최저가, N = 인원(4 또는 8)

| 항목 | 식 | 의미 |
| --- | --- | --- |
| **추천 입찰가(선점)** | `floor(P × 0.95 × (N−1)/N ÷ 1.1)` | 판매 손익분기보다 약 10% 낮게 입찰해 이익을 남기는 값 |
| 판매 손익분기 | `floor(P × 0.95 × (N−1)/N)` | 낙찰 후 거래소에 팔 때(수수료 5%) 손해가 없는 최대 입찰가 |
| 사용 손익분기 | `floor(P × (N−1)/N)` | 낙찰 후 직접 쓸 때 손해가 없는 최대 입찰가 |

- 입찰금은 나머지 N−1명이 나눠 갖기 때문에 `(N−1)/N`을 곱합니다.
- 중간값은 반올림하지 않고 마지막에 **한 번만 내림**합니다(정수 분수 연산으로 오차 없음).
- 예) P = 7,776 → 4인: 추천 5,036 / 판매 5,540 / 사용 5,832, 8인: 추천 5,876 / 판매 6,463 / 사용 6,804

## 한국어 OCR 언어 팩 설치

이 프로그램은 Windows에 내장된 OCR을 쓰므로 **한국어 광학 문자 인식** 기능이 설치되어 있어야 합니다. 없으면 실행 시 안내 창이 뜹니다.

1. **설정 > 시간 및 언어 > 언어 및 지역**
2. **한국어**가 없으면 `언어 추가`로 한국어를 추가합니다.
3. 한국어 옆 `…` > **언어 옵션** > **언어 팩**과 **광학 문자 인식**을 설치합니다.
4. 프로그램을 다시 실행합니다.

## 운영정책 관련 안내

로스트아크 운영정책의 "불법 프로그램 정의"에 해당하지 않도록 아래 원칙으로 만들었습니다.

- **게임에 접근하지 않습니다.** 게임 프로세스·메모리·창 핸들을 열거나 읽거나 조작하지 않고, DLL 주입이나 그래픽 API 후킹 오버레이도 쓰지 않습니다.
- **캡처는 단축키(F8)나 [캡처] 버튼을 누른 순간 1회만** 합니다. 상시 감시, 주기적 캡처, 화면 변화 감지 같은 자동 캡처는 없습니다.
- **입력을 대신하지 않습니다.** 자동 입찰, 마우스 클릭, 키 입력 전송 기능이 없습니다. 숫자를 보여 주고 클립보드에 넣어 줄 뿐, 게임 입찰 칸에 붙여넣고 입찰하는 것은 사람이 직접 합니다.
- **미니 창은 일반 Windows 창**입니다. 게임 화면 안에 그려 넣지 않습니다.
- **네트워크 통신을 하지 않습니다.** 업데이트 확인이나 원격 시세 조회도 없습니다.
- 전역 단축키는 키보드 후킹이 아니라 Windows가 제공하는 단축키 등록 기능(RegisterHotKey)을 씁니다.
- 인원 자동 판별, 임의 인원, Open API 연동, 캡처 영역 지정 기능은 의도적으로 넣지 않았습니다.

### 붙여넣기 전용 모드
화면 캡처 기능까지 끄고 싶다면 미니 창의 **붙여넣기 전용 모드**를 체크하세요(또는 `config.json`에서 `"capture_enabled": false`).

- 전역 단축키를 등록하지 않고, 화면 캡처 함수도 전혀 호출하지 않습니다.
- 사용법: **Win+Shift+S** 로 경매 창을 잘라 복사 → 미니 창을 클릭 → **Ctrl+V**

> 이 프로그램의 이용 가능 여부는 **스토브 고객센터에 확인하는 것을 권장**합니다. 사용에 따른 책임은 사용자에게 있습니다.

## 설정과 기록 파일

`config.json` (exe와 같은 폴더)
```json
{
  "hotkey": "F8",
  "last_party_size": 4,
  "capture_enabled": true,
  "window_pos": [100, 100],
  "icon_pos": [1850, 980]
}
```
- `window_pos`: 펼친 창의 위치, `icon_pos`: 아이콘으로 접었을 때 사용자가 끌어다 놓은 아이콘 위치(옮긴 적이 없으면 `null`이고, 이때는 창 왼쪽 위에 접힙니다).

`history.csv` (exe와 같은 폴더, UTF-8 BOM이라 엑셀에서 바로 열림)
```
시각,아이템명,거래소최저가,인원,추천입찰가,실제낙찰가
2026-11-04 21:30:00,유물 결투의 대가 각인서,17500,4,11335,
```
- 인식에 성공할 때마다 1행이 추가됩니다. 같은 아이템·가격을 2초 안에 다시 인식하면 1건으로 칩니다.
- 엑셀에서 파일을 열어 두면 Windows가 파일을 잠가 기록이 저장되지 않습니다(상태줄에 "기록 저장 실패" 표시). 엑셀을 닫고 다시 인식하세요.
- `config.json`이 깨져서 읽을 수 없으면 `config.json.bak`으로 백업하고, 안전하게 **붙여넣기 전용 모드**로 시작합니다.

## 빌드

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
- `.venv` 생성 → 의존성 설치 → PyInstaller(onefile, windowed) → `dist\LoaAuctionCalc.exe`
- PyInstaller 설정은 `LoaAuctionCalc.spec`에 있습니다. PySide6·Pillow가 함께 끌고 오지만 이 앱은 쓰지 않는 파일(Qt Quick/QML·PDF·네트워크/TLS 플러그인, 소프트웨어 OpenGL, Qt 번역 파일, AVIF·글꼴 엔진 등)을 빼서 exe를 작게 만듭니다. exe는 실행될 때마다 임시 폴더에 풀리므로, 작을수록 시작이 빠릅니다.
- 프로그램 아이콘(어두운 바탕의 골드 코인 + 경매 망치)은 `loa_auction/icon.py`가 코드로 그립니다. 빌드할 때 `build\icon\LoaAuctionCalc.ico`(16~256px)를 만들어 exe에 넣고, 실행 중에는 같은 그림을 창·작업 표시줄 아이콘으로 씁니다. 저장소에는 이미지 파일을 두지 않습니다. 아이콘 파일만 따로 만들려면 `.\.venv\Scripts\python -m loa_auction.icon 경로.ico`
- `fixtures\sample_<이름>_<가격>.png` 이미지가 있으면 exe에 넣고, 빌드 마지막에 `--selftest`로 OCR까지 검사합니다. 이미지가 없어도 빌드는 성공합니다(이때 자체 검사는 계산만 확인하고 "OCR 샘플 없음"을 출력).
- 자체 검사만 따로 실행하기: 창 프로그램(--windowed)이라 PowerShell이 끝날 때까지 기다리지 않으므로 아래처럼 실행합니다. `0`이 나오면 통과이고, 자세한 결과는 `dist\selftest.log`에 저장됩니다.
  ```powershell
  (Start-Process .\dist\LoaAuctionCalc.exe -ArgumentList '--selftest' -Wait -PassThru).ExitCode
  Get-Content .\dist\selftest.log -Encoding UTF8
  ```
